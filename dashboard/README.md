# 🚀 GDG on Campus Aswan • Power BI Style Attendance Dashboard
### لوحة التحليلات ومسارات الحضور لمجتمع Google Developer Groups on Campus - Aswan (GDG Aswan)

تم تصميم وتطوير هذه المنظومة بالكامل كـ **Business Intelligence Dashboard** تفاعلية مطابقة لبيئة وتجربة **Power BI Desktop & Power BI Service**:
- **قائمة الصفحات الجانبية (Power BI Pages Panel):** تنقل جانبي رأسي سلس بين صفحات التقرير مع إمكانية الطي والتوسيع.
- **شريط الحالة السفلي (Power BI Bottom Status Bar):** يتيح التنقل المباشر بين الصفحات (`‹ السابق` / `التالي ›`) ومتابعة حالة التقرير.
- **شريط المرشحات وسلايسرز (Slicers & Context Bar):** عرض فوري لعوامل التصفية ومؤشرات الأداء.
- **بطاقات المؤشرات (Power BI Card Visuals):** مؤشرات أداء رقمية بارزة مع خطوط الألوان المميزة.
- **الهوية البصرية الرسمية:** شعار GDG `< >` الرسمي بألوان جوجل الأربعة وشريط جوجل العلوي المميز.

## 🌟 الأقسام والدايجرامات المدمجة (Dashboard Analytics)

### 1. 📊 النظرة العامة والتحليلات (Overview & Analytics)
- **بطاقات الأداء السريع (KPIs):**
  - إجمالي الأفراد الحقيقيين المستقلين (**155 شخصاً**).
  - إجمالي مرات الحضور المؤكدة في كافة الورش (**124 حضوراً**).
  - عدد المشتركين المستمرين الذين حضروا ورشتين أو أكثر (**21 مشتركاً**).
  - متوسط نسبة الحضور العام عبر الورش (**50.4%**).
- **الدايجرام الأول: المسار الزمني لتدفق الحضور والتسجيل (Timeline Flow Chart):**
  - منحنى بياني يوضح التطور الزمني لأعداد الحضور الفعلي والمسجلين من أول ورشة وحتى الختام.
- **الدايجرام الثاني: معدل الالتزام والغياب لكل ورشة (Show-up vs No-Show):**
  - رسم بياني يقارن نسبة من حضر فعلياً مقابل من سجل ولم يحضر لكل ورشة على حدة.
- **توزيع ولاء وتكرار الحضور (Loyalty Donut Chart):**
  - مخطط دائري يوضح كم شخص حضر ورشة واحدة، ورشتين، 3، 4، أو 5 ورش.
- **الدايجرام الثالث: مصفوفة التقاطع بين التراكات (Cross-Track Overlap Heatmap):**
  - جدول تفاعلي ملون يوضح كم شخص حضر تراكين معاً (مثلاً: 9 مشتركين جمعوا بين AI و Python، و8 بين AI و Web Dev).

### 2. 💻 التراكات والسيشنز (Tracks & Sessions Breakdown)
- أزرار تنقل تفاعلية فورية بين جميع الورش الخمسة:
  - **Web Dev 1**
  - **AI Session**
  - **Python Workshop**
  - **SWE 1**
  - **Web Dev 2**
- شريط إحصائي لحظي لكل ورشة: عدد المسجلين، الحضور المؤكد، نسبة الحضور، التوزيع بين الأولاد والبنات، ونوع الهوية (جامعة أم قومي).
- جدول مخصص لمشتركي كل ورشة مع فلترة فورية بالاسم أو الهاتف وحالة الحضور (`حاضر مؤكد` أو `مسجل غائب`).

### 3. 👥 مقارنة الجنسين والاستمرارية (Gender & Loyalty)
- **المقارنة العامة:**
  - **أولاد (Male):** 77 مشتركاً (49.7%).
  - **بنات (Female):** 78 مشتركة (50.3%).
- **مقارنة الحضور حسب الجنس في كل ورشة:** رسم بياني يوضح إقبال الشباب مقابل البنات في كل تراك.
- **الدايجرام الرابع: مقارنة التزام الأولاد والبنات في الاستمرارية (Gender vs Loyalty Breakdown):**
  - رسم بياني يوضح أعداد الأولاد مقابل البنات اللاتي حضرن ورشة واحدة، ورشتين، 3، 4، أو 5 ورش عمل (يوضح أن البنات أكثر استمرارية بـ 4 أضعاف في الحضور المتكرر).

### 4. 🎓 نوع التسجيل ودفعات الجامعة (Registration Types & Cohorts)
- **المقارنة بين طلاب الأكاديمية والجمهور الخارجي:**
  - طلاب مسجلون برقم قيد جامعي (**63 طالباً**).
  - مسجلون بالرقم القومي من خارج الأكاديمية (**85 مشتركاً**).
  - مسجلون بالاثنين معاً (**مشتركان**).
  - تسجيل ورقي بالاسم فقط (**5 مشتركين**).
- **الدايجرام الخامس: توزيع الدفعات الجامعية في كل تراك (Cohorts per Track Breakdown):**
  - رسم بياني مكدس (Stacked Bar) يوضح نسبة طلاب سنة أولى (2026)، وسنة ثانية (2025)، وسنة ثالثة (2024)، والجمهور الخارجي في كل ورشة.
- **إجمالي دفعات طلاب الأكاديمية:** رسم بياني شريطي لجميع طلاب الأكاديمية حسب سنة الالتحاق.

### 5. 🔍 دليل وبحث الحضور الذكي (Smart Attendees Directory)
- **بحث فوري في كل الحقول:** ابحث بالرقم القومي (14 رقم)، أو رقم القيد الجامعي (9 أرقام، مثل `241009155`)، أو الاسم، أو الهاتف، أو الإيميل.
- **فلاتر متعددة متزامنة:** تصفية بالسيشن، بعدد مرات الحضور، أو بالجنس.
- **البحث السريع في الهيدر العلوي (Header Quick Search):** قائمة منسدلة ذكية تظهر نتائج فورية أثناء الكتابة وتفتح الملف بضغطة زر.

### 6. 🪪 بطاقة بروفايل المشترك (Attendee Profile Modal)
عند النقر على أي شخص يفتح كارت بروفايل كامل يحتوي على:
- الاسم بالكامل وطرق كتابته البديلة.
- أرقام القيد الجامعي والقومي والإيميل والهاتف.
- الدفعة الجامعية والتصنيف الأكاديمي.
- 5 بطاقات تفاعلية توضح موقفه في كل ورشة (حاضر / غائب / لم يسبق له التسجيل).
- ملاحظات الحضور المعتمدة.

## 🖥️ كيف تشغل الداشبورد على جهازك؟ (How to Run Locally)

1. ادخل إلى المجلد:
   ```
   D:\GDG\GDG_Dashboard\
   ```
2. اضغط مرتين (Double Click) على ملف:
   ```
   index.html
   ```
   سيفتح فوراً في متصفحك بكامل سرعته ومميزاته حتى لو كان الجهاز **غير متصل بالإنترنت**.

## 🌐 كيف تشارك الداشبورد أونلاين؟ (How to Share Online)

1. **عبر GitHub Pages (مجاناً وبسهولة):**
   - ارفع محتويات فولدر `GDG_Dashboard` على مستودع GitHub جديد.
   - من إعدادات المستودع (Settings) فعل **Pages**؛ ستحصل على رابط حي ومباشر ترسله لفريق التنظيم.
2. **عبر Netlify Drop:**
   - اسحب فولدر `GDG_Dashboard` وأفلته في [Netlify Drop](https://app.netlify.com/drop) وسيعطيك رابطاً حياً في ثوانٍ.
3. **مشاركة مباشرة:**
   - يمكنك ضغط الفولدر كملف ZIP ومشاركته على تليجرام أو واتساب؛ وسيعمل فوراً عند أي شخص بمجرد فتح `index.html`.

## 🔄 كيف تحدث البيانات في المستقبل إذا أضفت سيشن جديدة؟

إذا تم تعديل ملف `Master_Attendance_final.xlsx` أو إضافة ورش جديدة:
فقط شغّل السكريبت التالي في التيرمينال:
```bash
python D:\GDG\GDG_Dashboard\export_data.py
```
سيتم تحديث ملفات البيانات فوراً، وبمجرد عمل Refresh لصفحة `index.html` ستظهر كل الإحصائيات الجديدة مباشرة!
