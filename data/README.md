# 📊 GDG on Campus Aswan — Master Attendance Dataset & Audit Report

This folder contains the verified, audited, and cleaned master attendance records for the 5 technical workshops organized by **Google Developer Groups on Campus — AAST Aswan (GDG Aswan)**:

1. **`Master_Attendance_final.xlsx`**:
   - The authoritative clean Excel workbook containing all 155 unique participants across the 5 workshop sessions:
     - `Web Dev 1`
     - `AI Session`
     - `Python Workshop`
     - `SWE 1`
     - `Web Dev 2`
   - Complete attributes: Unified Name, University Student ID, 14-digit Egyptian National ID, Email, Phone Number, Inferred Gender, and Attendance matrix.
   - Formatted with professional Google brand headers and verified formulas.

2. **`VERIFICATION_REPORT.md`**:
   - The full 10-point audit verification report documenting data validation, cross-track engagement, deduplication, and integrity checks.

3. **Interactive Dashboard**:
   - Check the [`../dashboard/`](../dashboard/) directory for the full interactive Power BI-style analytics dashboard (`index.html`).
