# GDGoC AAST Aswan — Logo Kit

Clean, high-resolution logo variations reconstructed from the supplied partnership poster.

## Folder guide

- `01_Full_Logos`: horizontal icon + GDGoC + AAST Aswan, with transparent and solid backgrounds
- `02_Icon_Only`: four-color, black, white, blue icons; suitable for tiny spaces
- `03_Stacked_Logos`: vertically arranged icon and name
- `04_Watermarks`: translucent PNG versions for posters, slides and videos
- `05_Social_Avatars`: ready-to-post square 1024 x 1024 icons and logo avatars
- `06_Wordmarks`: text-only logos
- `07_SVG_Vectors`: crisp scalable versions for print and editing; letters are vector outlines
- `08_Previews`: overview sheet to compare variants

## Background selection

- `For_Dark`: white main name + blue subtitle; transparent background; intended for dark slides/posts.
- `For_Light`: dark main name + blue subtitle; transparent background; intended for white/light surfaces.
- `All_White`: entirely white, transparent, excellent on branded dark backgrounds.
- `All_Black`: entirely black, transparent, best on white or pale backgrounds.
- `All_Brand_Blue`: a single blue tone, transparent.
- `On_Dark_Background` / `On_White_Background`: includes the actual background, not transparent.

## Technical notes

PNG files are high resolution and have transparency unless their name says `On_*_Background` or they are avatars. SVG files are true vector artwork with letters converted to paths (no external fonts required). The mark was geometrically redrawn and typography was recreated using Inter because the supplied source was a low-resolution image. These are polished reconstructions, not official master brand files. Keep clear space and do not stretch proportions.
